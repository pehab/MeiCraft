Zwei virtuelle Joysticks: links bewegen, rechts horizontal und vertikal umsehen. Die Blickrichtung lässt sich unabhängig von der Bewegung steuern, auch dauerhaft nach unten. Eine Totzone verhindert versehentliches Drehen. Die Aktionstasten wurden dafür neu angeordnet. Beim Loslassen, Abbrechen einer Berührung und bei Fokusverlust stoppt die Steuerung.

Vorhandene Welten und die Update-Einstellungen bleiben erhalten. Die neue Version wird unter ☰ → Updates angeboten.
