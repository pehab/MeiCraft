Festes Querformat und mehrere eigene Welten.

- Das Spiel startet im Querformat, auch wenn das Handy auf Hochformat gesperrt ist. Beide horizontalen Haltungen funktionieren.
- Unter ☰ → Neue Welt … eine zusätzliche Welt mit Namen, optionalem Seed und Moduswahl (Kreativ/Story) anlegen.
- Unter ☰ → Welten laden gespeicherte Welten auswählen und fortsetzen. Die aktive Welt ist markiert.
- Welt umbenennen, ohne Spielstand oder Bauwerke zu verschieben.
- Jede Welt speichert automatisch und unabhängig; vor einem Weltwechsel wird die offene Welt gespeichert.
- Beim Start wird die zuletzt verwendete Welt automatisch geladen.
- Vorhandene Kreativ- und Storyspielstände aus 0.1.0/0.2.0 bleiben erhalten und erscheinen als Meine Kreativwelt bzw. Meine Storywelt.
- Die APK verwendet den bisherigen Signierschlüssel und lässt sich über die vorhandene Installation aktualisieren.
