# Prüfstand 1.0.0-rc.1 · 2026-11-01

## Lokal bestanden

- `bash test.sh`: gesamte bestehende Logiksuite und 153 neue Geometrie-/Puffer-/Diagnoseverträge.
  Fester Gelände-Hash unverändert.
- `bash scripts/test-update-contract.sh`: 27 Updateprüfungen.
- `npm run test:rules` unter Java 21 / Node 24: 37 Firestore-Tests, keine Fehler.
- `build-local.sh`: APK mit API 37 gebaut; Signaturstruktur geprüft.
- `test-android-build.sh`: Android-Instrumentierungs-APK kompiliert und gebaut.

Die lokal erzeugten APKs verwenden ausschließlich einen lokalen Testschlüssel, nicht den
vorhandenen Produktionsschlüssel. Sie sind kein installierbares Update der bestehenden
signierten Geräteinstallation. Der Produktionsschlüssel gehört weiterhin in den bestehenden
GitHub-Signierworkflow. Es wurden keine Produktions-Firebase-Anfragen ausgeführt.

## Kontrollierter Geometrie-Benchmark

Linux / OpenJDK 17; 40 Aufwärmdurchläufe, 101 alternierende Messungen je Kern und Szene.
Ohne tatsächlichen OpenGL-Upload. Zeiten sind ein einzelner lokaler Lauf, kein Tablet-Nachweis.

| Szene | 0.8.3 p50 / p95 (ms) | Kandidat p50 / p95 (ms) |
| --- | ---: | ---: |
| Gemischte Materialien mit Ritualhitze | 1,458 / 3,270 | 0,913 / 1,196 |
| Gelände | 0,138 / 0,222 | 0,062 / 0,113 |
| Online-Bereichsgrenze | 0,178 / 0,326 | 0,064 / 0,097 |
| Leer | 0,038 / 0,050 | 0,020 / 0,021 |

In allen Vertragszenen stimmen Anzahl, Reihenfolge und Float-Bits der Vertices, UVs und
Helligkeitswerte überein. Wiederholte Aufbauten gleicher Größe ersetzen das Geometriearray
nicht. Der Renderer verwendet außerdem seinen direkten Uploadpuffer wieder.

## Kontrollierter Firestore-Vergleich

205 Blockdokumente mit gemeinsamem Zeitstempel; nach dem vollständigen Snapshot wird
eines verändert. Die alte inklusive Abfrage lädt auf ihrer ersten Seite erneut 200
Dokumente; der neue exklusive Snapshot-Filter liefert genau das eine später veränderte
Dokument. Beide ersten Seiten und die restlichen fünf Dokumente werden aus demselben
Snapshot gelesen. Projektion erhält die Versionsmetadaten. Banned/Outsider-Zugriffe
auf den neuen batchGet-Pfad werden verweigert.

Keine Prozentangabe für eine vollständige Spielsession: ruhende Welten sparen dadurch
keine Dokumentlesungen; batchGet und Projektionen benötigen zusätzliche Anfragebytes.
Die drei Dokument-Schreibvorgänge pro Block bleiben gleich. Gesendete Anfrageinhalte
werden deshalb zusätzlich diagnostiziert.

## Offen vor endgültiger Freigabe

- Gradle/Lint: lokaler Gradle-Download scheiterte an `Network is unreachable`.
- Android 11/17: Test-APK gebaut, Instrumentierung noch nicht ausgeführt.
- Tatsächliche Tablets: Frameabstände einschließlich p99, Aktionsbestätigung, Sichtbarkeit
  bei Mitspielern, kalter Start, Grenzen und Verbrauch im gleichen Mehrgeräte-Ablauf.
- GitHub-PR und CI: Push durch automatische Freigabeprüfung wegen fehlender ausdrücklicher
  Zustimmung zur öffentlichen Veröffentlichung dieses Entwicklungsstands abgelehnt.
  Es erfolgte kein erneuter Veröffentlichungsversuch über einen anderen Weg.

Die vorliegenden Ergebnisse rechtfertigen einen Testkandidaten, keine endgültige 1.0-Freigabe.
